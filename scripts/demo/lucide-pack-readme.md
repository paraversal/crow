# Example icon pack: Lucide

A complete local icon pack: file and folder icons from [Lucide](https://lucide.dev) (ISC, see
`LICENSE-lucide.txt`) mapped to extensions, folder names and the generic file and folder, each
tinted with a theme role or palette hue.

Install it by copying this folder into Crow's config folder under its id, then choose it:

```bash
mkdir -p ~/.config/crow/icon-packs
cp -R docs/examples/icon-pack ~/.config/crow/icon-packs/lucide
```

Settings ▸ Appearance ▸ Icon pack lists it as "Lucide" (or set `icon_pack = "lucide"` in
`settings.toml`). The pack's folder name is its id.

Edit `pack.toml` to change what maps to what. Icons are plain `.svg` files in the `icons/`
folder beside it, and only SVG is supported; see [docs/plugins.md](../../plugins.md) for the
format and limits. The pack is generated by `scripts/demo/make-lucide-pack.sh`, which also
shows how to build one from any SVG set.
