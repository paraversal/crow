# Built-in theme sources

The built-in themes are Base24 ports with role overrides tuned for Crow (contrast
checked by `crow-theme`'s tests).

| Theme | Source | Licence |
| --- | --- | --- |
| Catppuccin Latte, Mocha | https://github.com/catppuccin/catppuccin | MIT |
| Gruvbox Light, Dark | https://github.com/morhetz/gruvbox (Base24 port by Dawid Kurek) | MIT |
| Solarized Light, Dark | https://ethanschoonover.com/solarized (Base24 port by aramisgithub) | MIT |
| Finder Light, Dark | Colours sampled from macOS by Crow (`scripts/sample-system-colors.swift`) | Crow's own |
