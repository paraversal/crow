## Decisions
- Branch `m7-h4-3` from `main` @ b130169 (H1–H3, H4 batches 1–2, H5, H6, H7 merged). — plan.
- #10: clear the pane filter when a new item is created, so the new row and its rename field are visible. Recommended as the Finder-like "the new item is what you are acting on" behavior; user approved. — user + plan.
- #13/#17: enforce the overlay focus contract in the window, not at each deferred focus site. `CrowWindow::overlay_focus_surfaces` is shared by the fuzzer's invariant and the render-time trap, so the two cannot drift. A deferred re-focus (GPUI's own pattern for focus after render) is the only way to move focus out of a render; the alternative — cancel pending renames from every overlay opener — misses other deferred focus sites (`focus_list_after_filter`) and future ones. — cause + code convention.
